## 🚀 How to Deploy to GitHub Pages in 60 Seconds

This project is structured as a **zero-dependency, single-file deployable website** (`index.html`). No build tools, Node.js, or webpack required!

### Step 1: Push or Upload to a GitHub Repository
1. Create a new GitHub repository named `ultrahuman-dual-suite` (or your preferred name).
2. Upload `index.html` and `README.md` to the repository root, or push via git:
   ```bash
   git init
   git add .
   git commit -m "Initial launch: Ultrahuman Dual Suite website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (top right tab).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment > Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Wait 30 seconds, refresh the page, and your live URL will appear (e.g. `https://<your-username>.github.io/<your-repo-name>/`).
